# Shared task list — Lucky and TheMAN

One source of truth for who owns each task and its status. Both Muse
accounts (Lucky and TheMAN) read this file and update it when a task is
made, changes owner, or changes status. Rajo is the bridge when a task
needs a decision only he can make.

## How it works

- When a task is made, the Muse who made it (or Rajo) adds a row to
  **Active tasks** with the owner and status.
- The owner updates the status when it moves (in progress, done, blocked).
- When a task is done, move it to **Done** with the date and the result.
- When a task is waiting on Rajo, move it to **Waiting on Rajo**.
- Never delete a task. Move it, do not erase it.
- Status values: `planned`, `in progress`, `done`, `blocked`, `waiting on Rajo`.
- Owner values: `Lucky` or `TheMAN`.
- Do not put secrets, passwords, tokens, or payment details in this file.

  Run the verification checklist before delivering any video.
- Outcome rule (Rajo, 2026-11-12, ALL content): every piece of content is built promise, build, payoff. The opening creates an expectation of a specific gain, the middle builds toward it, and the end delivers one concrete piece of valued information the audience can retell. Curiosity alone is not enough, and a symbol or an image alone is not a payoff. Post captions carry the promise too.
